# Рукописный лист

Печатаешь текст — получаешь картинку рукописного конспекта на тетрадном
или А4 листе с реальными физическими пропорциями. Экспорт PNG/JPEG
(в браузере) и многостраничный PDF (через backend).

## Структура

- `frontend/` — статика (canvas-рендер текста, никакого билда не требует)
- `backend/` — Express + pdfkit, один эндпоинт `POST /api/pdf`, собирает
  многостраничный PDF из PNG-страниц

## Деплой (Render, отдельные сервисы)

- Frontend (static site): https://handwriter-51xq.onrender.com
- Backend (web service): https://handwriter-api.onrender.com

Оба подключены к этому репо (main), автодеплой на каждый push.
`frontend/index.html` обращается к `BACKEND_URL` (захардкожен вверху
скрипта) только для сборки PDF — PNG/JPEG работают полностью локально
в браузере, backend не нужен.

Backend на бесплатном плане Render засыпает без трафика — первый PDF-запрос
после простоя может занять 30-50 сек, дальше быстро.
